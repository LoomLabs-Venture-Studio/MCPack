**GREEN phase**: Create `src/build.ts` implementing `createMCPackServer(config)`.

The function is SYNCHRONOUS (not async). Implementation:

1. Runtime validation: throw if `!config.name`, `!config.version`, `!config.tools || config.tools.length === 0`
2. Snapshot config: `const roles = config.roles ? { ...config.roles } : undefined; const defaultRole = config.defaultRole;`
3. defaultRole validation: warn if defaultRole set and roles set but `!roles[defaultRole]`
4. Build dispatch map: `Map<string, handler>` from config.tools. Warn on duplicates with exact message: `MCPack: duplicate tool name "${tool.name}" in config.tools. Last definition wins.`
5. Strip handlers: `const tools: Tool[] = config.tools.map(({ handler, ...tool }) => tool);`
6. Create engine: `new MCPackEngine(tools, config)`
7. Create server: `new Server({ name: config.name, version: config.version }, { capabilities: { tools: {} } })`
8. Set tools/list handler: returns `engine.handleToolsList()`
9. Set tools/call handler with:
   - Null argument guard: `(request.params.arguments == null ? {} : request.params.arguments)`
   - Route search_tools to engine
   - Role check with `isToolAllowed(name, defaultRole, roles)` -- return `{ content: [{ type: 'text', text: 'Unknown tool: ${name}' }], isError: true }` if blocked
   - Dispatch lookup -- return unknown tool error if not in map
   - Execute handler with `MCPackHandlerContext { toolName: name, sessionId: sid, role: defaultRole }`
   - Call `engine.markToolLoaded(name, sessionId)` after successful execution
   - Normalize result with `normalizeResult()` helper
   - Catch errors: `Tool "${name}" failed: ${err.message ?? 'Unknown error'}`
10. Return `{ server, handle: { destroy: () => engine.destroy(), stats: () => engine.stats() } }`

`normalizeResult(value: unknown)` helper function (module-level, not exported):
- `null`/`undefined` -> `{ content: [{ type: 'text', text: '' }] }`
- `string` -> `{ content: [{ type: 'text', text: value }] }`
- Has `content` array -> passthrough as ToolCallResult
- Object -> `{ content: [{ type: 'text', text: JSON.stringify(value) }] }`

Add deprecation-awareness comment after imports (same as wrap.ts).
