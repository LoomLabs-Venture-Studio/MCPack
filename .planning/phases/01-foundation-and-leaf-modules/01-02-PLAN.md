**Function signature:**
```typescript
export function scoreAndRank(
  query: string,
  index: ToolIndexEntry[],
  limit?: number
): ToolIndexEntry[]
```

**Algorithm:**
1. Compute effective limit: `Math.min(limit ?? DEFAULT_LIMIT, MAX_LIMIT)`
2. Tokenize query: `query.toLowerCase().split(/\s+/).filter(Boolean)`
3. For each entry in index, compute score:
   - For each query token:
     - If `entry.name.toLowerCase() === token` -> add EXACT_NAME
     - Else if `entry.name.toLowerCase().includes(token)` -> add PARTIAL_NAME
     - If `entry.description.toLowerCase().includes(token)` -> add DESCRIPTION
     - If `entry.keywords.some(k => k.includes(token))` -> add KEYWORD
     - If `entry.schemaKeywords.some(k => k.includes(token))` -> add SCHEMA_PROPERTY
4. Filter entries with score > 0
5. Sort descending by score (stable sort -- if equal scores, preserve original order)
6. Slice to effective limit
7. Return the ToolIndexEntry array (NOT the scored wrappers)

CRITICAL: Do NOT mutate the input `index` array. Create a new array with `index.map(...)` for scoring. Never call `index.sort()`.

CRITICAL: Use `includes()` for substring matching per CONTEXT.md locked decision. No regex, no stemming, no fuzzy matching.

```typescript
export class SessionRegistry {
  private sessions: Map<string, Session>;
  private timer: ReturnType<typeof setInterval>;
  private ttl: number;

  constructor(config?: SessionConfig)
  getOrCreate(id: string, role: string): Session
  destroy(): void
  private cleanup(): void
}
```

**Constructor:**
- `this.ttl = config?.ttl ?? 7200000` (2 hours default)
- `this.sessions = new Map()`
- `this.timer = setInterval(() => this.cleanup(), 900000)` (15 minutes)
- `this.timer.unref()` -- CRITICAL: prevents blocking Node.js process exit (SESS-03)

**getOrCreate(id: string, role: string): Session**
1. Check `this.sessions.get(id)`
2. If exists AND `Date.now() - existing.lastActiveAt > this.ttl` -> delete it (lazy expiry), fall through to create
3. If exists AND not expired -> update `lastActiveAt = Date.now()` (sliding TTL), return it
4. If not exists (or was just deleted) -> create new Session:
   ```typescript
   const session: Session = {
     id,
     role,
     loadedTools: new Set(),
     queryLog: [],
     createdAt: Date.now(),
     lastActiveAt: Date.now(),
   };
   this.sessions.set(id, session);
   return session;
   ```

**destroy(): void**
- `clearInterval(this.timer)`
- `this.sessions.clear()`

**cleanup(): void (private)**
- Iterate `this.sessions` entries
- Delete any where `Date.now() - session.lastActiveAt > this.ttl`

Create `src/roles.ts` with two exported functions.

**Function 1: resolveRoleAccess**
```typescript
export function resolveRoleAccess(
  role: string | undefined,
  roles: RoleConfig | undefined,
  index: ToolIndexEntry[]
): ToolIndexEntry[]
```

Logic:
1. If `!roles || Object.keys(roles).length === 0` -> return `index` (no roles config = all visible)
2. If `!role` -> return `[]` (no role on session = nothing visible, secure default)
3. Call `getAllowedTools(role, roles, new Set())` to resolve the set of allowed tool names
4. If result is `'*'` -> return `index` (wildcard = all visible)
5. Otherwise filter: `index.filter(entry => allowed.has(entry.name))`

**Function 2: isToolAllowed** (for Phase 2 tools/call defense-in-depth enforcement)
```typescript
export function isToolAllowed(
  toolName: string,
  role: string | undefined,
  roles: RoleConfig | undefined
): boolean
```

Logic:
1. If `!roles || Object.keys(roles).length === 0` -> return `true`
2. If `!role` -> return `false`
3. Call `getAllowedTools(role, roles, new Set())`
4. If result is `'*'` -> return `true`
5. Return `allowed.has(toolName)`

**Internal function: getAllowedTools** (NOT exported)
```typescript
function getAllowedTools(
  role: string,
  roles: RoleConfig,
  visited: Set<string>
): Set<string> | '*'
```

Logic:
1. If `visited.has(role)` -> return `new Set()` (cycle protection)
2. `visited.add(role)`
3. `const definition = roles[role]`
4. If `!definition` -> return `new Set()` (unknown role)
5. If `definition === '*'` -> return `'*'` (wildcard)
6. Iterate `definition` array:
   - If `roles[item] !== undefined` -> it's a role reference, recurse: `getAllowedTools(item, roles, visited)`
     - If recursive result is `'*'` -> return `'*'` (wildcard propagates)
     - Otherwise add all items from the returned Set
   - Else -> it's a tool name, add to result Set
7. Return result Set
