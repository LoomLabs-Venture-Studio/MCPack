Create `test/harness/stripe-harness.ts` -- the complete integration harness. This is a standalone script run via `npx tsx`, NOT a vitest test file (per D-07, must not be named *.test.ts).

**Structure:**

1. **API key check (D-10):** Check `process.env.STRIPE_API_KEY` at script start. If not set, print:
   ```
   STRIPE_API_KEY not set. Skipping Stripe MCP harness.
   Set STRIPE_API_KEY to run: STRIPE_API_KEY=sk_test_xxx npm run harness
   ```
   Then `process.exit(0)` (clean exit, not error).

2. **TypeScript interfaces:**
   ```typescript
   interface QueryResult {
     query: string;
     vanilla_tool_count: number;
     mcpack_tool_count: number;
     vanilla_chars: number;
     mcpack_chars: number;
     char_reduction_pct: number;
     estimated_tokens_vanilla: number;
     estimated_tokens_mcpack: number;
     estimated_tokens_saved: number;
   }

   interface AggregateResult {
     total_vanilla_chars: number;
     total_mcpack_chars: number;
     overall_reduction_pct: number;
     total_estimated_tokens_vanilla: number;
     total_estimated_tokens_mcpack: number;
     total_estimated_tokens_saved: number;
   }

   interface HarnessReport {
     generated_at: string;
     stripe_tool_count: number;
     queries: QueryResult[];
     aggregate: AggregateResult;
     note: string;
   }
   ```

3. **Connect to Stripe MCP server:**
   ```typescript
   import { Client } from '@modelcontextprotocol/sdk/client/index.js';
   import { StdioClientTransport } from '@modelcontextprotocol/sdk/client/stdio.js';

   const transport = new StdioClientTransport({
     command: 'npx',
     args: ['-y', '@stripe/mcp', '--api-key', process.env.STRIPE_API_KEY!],
   });
   const client = new Client({ name: 'mcpack-harness', version: '0.1.0' });
   ```
   Wrap entire execution in try/finally to ensure `client.close()` is called (Pitfall 1 from research).

4. **Get vanilla tools:**
   ```typescript
   await client.connect(transport);
   const { tools } = await client.listTools();
   ```
   The `tools` array is the vanilla payload. Compute `vanillaChars = JSON.stringify(tools).length` per D-08.

5. **Query set (D-09 -- multiple queries, Claude's discretion):**
   ```typescript
   const queries = [
     'create a payment',
     'manage customers',
     'subscription billing',
     'issue refund',
     'list invoices',
   ];
   ```
   These span 5 different Stripe API domains (payments, customers, subscriptions, refunds, invoicing).

6. **Run each query through MCPack index/search:**
   ```typescript
   import { buildIndex } from '../../src/index-builder.js';
   import { scoreAndRank } from '../../src/search.js';

   const index = buildIndex(tools);

   for (const query of queries) {
     const results = scoreAndRank(query, index, 5);
     const mcpackChars = JSON.stringify(results.map(r => r.schema)).length;
     // ... build QueryResult
   }
   ```

7. **Per-query result calculation (D-13):**
   For each query, compute:
   - `vanilla_tool_count`: `tools.length`
   - `mcpack_tool_count`: `results.length`
   - `vanilla_chars`: `JSON.stringify(tools).length` (same for all queries -- full payload)
   - `mcpack_chars`: `JSON.stringify(results.map(r => r.schema)).length`
   - `char_reduction_pct`: `(1 - mcpack_chars / vanilla_chars) * 100`
   - `estimated_tokens_vanilla`: `Math.ceil(vanilla_chars / 4)` (D-15)
   - `estimated_tokens_mcpack`: `Math.ceil(mcpack_chars / 4)` (D-15)
   - `estimated_tokens_saved`: `estimated_tokens_vanilla - estimated_tokens_mcpack`

8. **Aggregate calculation (D-14):**
   Sum all per-query values:
   - `total_vanilla_chars`: sum of all vanilla_chars
   - `total_mcpack_chars`: sum of all mcpack_chars
   - `overall_reduction_pct`: `(1 - total_mcpack_chars / total_vanilla_chars) * 100`
   - Token estimates: sum of per-query token values

9. **Report output (D-11, D-12, D-16, D-17):**
   - Write JSON to `test/harness/report.json` using `writeFile` from `node:fs/promises`
   - Use `dirname(fileURLToPath(import.meta.url))` for `__dirname`
   - JSON includes `note` field: `"Numbers represent character counts of serialized JSON payloads, not actual LLM tokens. Estimated tokens use chars/4 approximation."`
   - Print console summary (structured text, not table):
     ```
     === MCPack Token Reduction Report ===

     Stripe MCP tools discovered: NN

     Query: "create a payment"
       Tools: NN vanilla -> NN MCPack
       Chars: NNNN -> NNNN (NN.N% reduction)
       Est. tokens: NNNN -> NNNN (saved ~NNNN)

     [... repeat for each query ...]

     --- Aggregate ---
     Total chars: NNNN -> NNNN
     Overall reduction: NN.N%
     Total est. tokens saved: NNNN

     Note: Numbers represent character counts of serialized JSON payloads,
     not actual LLM tokens. Estimated tokens use chars/4 approximation.

     Report written to test/harness/report.json
     ```

10. **Cleanup:** `client.close()` in finally block. Also add `process.on('exit', ...)` safety net per research Pitfall 1.
