  <action>
    Create `.github/workflows/` directory structure and `.github/workflows/docs.yml` with the following content (per D-17):

    ```yaml
    name: Deploy Docs

    on:
      push:
        branches:
          - main
        paths:
          - 'docs/**'
          - 'mkdocs.yml'
          - 'README.md'

    permissions:
      contents: write

    jobs:
      deploy:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4

          - name: Set up Python
            uses: actions/setup-python@v5
            with:
              python-version: '3.12'

          - name: Install MkDocs
            run: pip install mkdocs-material

          - name: Sync README to docs
            run: cp README.md docs/index.md

          - name: Deploy
            run: mkdocs gh-deploy --force
    ```

    Key details:
    - Triggers on push to main when docs/**, mkdocs.yml, or README.md change
    - Uses Python 3.12 and mkdocs-material (includes mkdocs)
    - Syncs README.md to docs/index.md before deploying (ensures they stay in sync even if someone edits README without updating docs/index.md)
    - Uses `mkdocs gh-deploy --force` to push to gh-pages branch
    - `permissions: contents: write` needed for gh-deploy to push to gh-pages branch
  </action>
